# Biblioteca de Babel

Projeto web inspirado na obra **A Biblioteca de Babel**, de Jorge Luis Borges.


## Funcionalidades

- Explorar a biblioteca;
- Navegar por câmaras, paredes, prateleiras e volumes;
- Acessar localizações aleatórias;
- Buscar textos;
- Visualizar volumes;
- Consultar informações sobre o projeto.

## Tecnologias

- HTML5;
- CSS3;
- JavaScript;
- Bootstrap 5.

## Estrutura

```text
biblioteca-babel/
├── index.html    # Página principal
├── buscar.html   # Página de busca
├── sobre.html    # Informações sobre o projeto
├── script.js     # Recursos interativos
├── style.css     # Estilos da aplicação
└── README.md     # Documentação do projeto
```

## Execução

Para executar o projeto, abra o arquivo `index.html` em um navegador. Não é necessário instalar dependências. A interface utiliza o Bootstrap por CDN, portanto uma conexão com a internet pode ser necessária para carregar seus estilos.
